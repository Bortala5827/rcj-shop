# rcj-shop

RCJ Lab storefront — **shop.955827.xyz**

A Cloudflare Pages single-page storefront selling custom question banks
(Anki decks + offline HTML practice pages) and done-for-you websites for
civil-service and job-interview candidates. Multilingual (EN / 中文 / 日本語).

## Live site

- **https://shop.955827.xyz/** — main storefront
- **https://dinner.955827.xyz/** — my own couple-order system (showcased on the page)
- **https://021100.xyz/** — a student's work (showcased on the page)

## What it does

- **Custom question banks** — practice in-browser (progress saved locally, no
  install) and downloadable offline HTML pages.
- **Anki memory decks** (.apkg) with spaced repetition.
- **Done-for-you websites** — built on Cloudflare Pages, student-built end to end.
- **Sing to Me 🎤** — a free featured action: sing a song, get the material free.
  Opens an in-page recording booth (mic + waveform, ≤60s). Independent of the
  rcj-stack "sing to me" system.
- **Student Work showcase** — collapsible cards showing real student projects
  (domain → Cloudflare → AI tools & APIs).

## Payment

- **Primary: Xianyu (闲鱼)** — manual checkout.
- **Secondary: PayPal (live mode)** — USD/CNY resolved automatically on the
  backend; the payment-result page is `return.html` (transaction return page,
  not indexed).
- Buyer receipts are **not** sent via Resend (low-volume private notifications
  like the dinner system are the exception that uses Resend).

## Tech stack

- **Cloudflare Pages** — static hosting, zero build step
  (`pages_build_output_dir = "."` in `wrangler.toml`)
- **Cloudflare D1** — shared database `rcj-analytics-d1`
  (binding `DB`), holds orders / leads / analytics across the RCJ suite
- **Vanilla HTML/CSS/JS** — single `index.html`, inline i18n dictionary, no
  framework, no build
- **GitHub Actions** — CI/CD via `cloudflare/wrangler-action`

## Deployment

Push to `main` triggers the workflow in `.github/workflows/deploy.yml`,
which runs `wrangler pages deploy . --project-name=rcj-shop --branch=main`.
No local wrangler token needed for CI — it uses `secrets.CF_API_TOKEN` and
`secrets.CF_ACCOUNT_ID`.

> The repo is `private: true`. There is no public clone / contribution path.

## i18n

Three languages (EN / 中文 / 日本語) via an inline dictionary keyed by
`data-i18n="..."` attributes on `index.html`. The default `<html lang="en">`
plus `hreflang` on the canonical link keeps English as the reference language.

## Maintenance notes

### Adding a student-work showcase card

Two cards live inside the `#showcase` block in `index.html`:

- **Student work** — i18n keys prefixed `sc*`
  (`scBadge`, `scTitle`, `scSub`, `scDesc`, `scTag1..3`, `scOpen`, `scToggleTip`)
- **My work** — i18n keys prefixed `my*`
  (`myBadge`, `myTitle`, `mySub`, `myDesc`, `myTag1..3`, `myToggleTip`)

To add a new card: copy one `.showcase-card` (or `.showcase` block), point the
links/img at the new site, and add the matching i18n keys for all three
languages. Screenshot assets go in `assets/`.

### Regenerating the dinner showcase screenshot

```sh
node shot-dinner.cjs
```

Uses the local Chrome channel via Playwright, navigates to
`https://dinner.955827.xyz/`, and writes `assets/showcase-dinner.jpg`.

### Sing to Me

The recording booth is fully inline in `index.html` (`.sing-feature`,
`.sing-overlay`, `.sing-booth`, `.sing-stage`). No separate service — it is
deliberately independent of the rcj-stack "sing to me" implementation.

## Notes

- `return.html` is intentionally `lang="zh-CN"` and excluded from the sitemap;
  it is a transaction return page, not a content page.
- `robots.txt` allows search-engine indexing but disallows AI-training crawlers
  (GPTBot, ClaudeBot, CCBot, etc.), matching the policy across 955827.xyz.
